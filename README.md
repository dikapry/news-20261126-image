One image summing up the world's news of Thursday 26 November 2026.
A hand-drawn editorial poster: 36 stories from 9 regions, three lead
illustrations, a map with pins, a UTC timeline, a by-the-numbers band and a
date-check box separating same-day reports from older stories.

`entry.png` is generated by `render.py` from the researched story index in that
file; every illustration, icon and map shape is drawn with PIL primitives.
No photographs, remote assets or copied artwork are used. `main.ts` is the
entrypoint the grader runs: it validates the PNG and copies it to `/output`.

## Run it

```sh
# In the browser: the image is entry.png at the repository root.
# Locally, regenerate it and place it in the output directory:
python3 render.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The grader sees exactly the bytes of `entry.png`: 1024 x 1024 pixels, under 1 MiB.
